## Data Types

- **Integer** (1, 2, 4, 8)
- **Float** (1.75, -0.25)
- **String** ("Hola", "Adios")
- **Boolean** (True, False)
- **List** (1, 2, 3) OR ("Torta", "Pan", "Cremona")
  - Mutable
  - Orderer
- **Tuple** (1, 3, 3)
  - Unmutable
  - Can´t be modified
- **Dictionary** ("name": "Nico", "age": "32", "country": "Argentina")
- **Sets** {1, 2, 3} OR set([1, 2, 3])
  - Unmutable
  - Not orderer


## POO Concepts

- Capsulation: Data and Methods are all together.
- Inheritance: Classes can be created based on parent classes.
- Abstraction: You can create an instance without knowing its methods.
