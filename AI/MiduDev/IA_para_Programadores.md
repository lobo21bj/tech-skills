## LLM (Large Language Model)


function(contexto) -> siguiente_token


Fase 1: Pre-Entrenamiento

Fase 2: Fine Tuning

Fase 3: RLFH (Reinforcement Learning from Human Feedback)


**Context Window**: Limite de numero de parametros que les podrías pasar a la funcion.

**system prompt / system message**: Como se tiene que comportar el modelo.

**Prompt messages**: Es el user prompt.

**Tokens**: LLM no habla con textos, habla con tokens. *Token != Texto*. Es un fragmento de texto, se divide segun el modelo. ej: gpt-tokenizer.dev o claude.tokenizer.vercel.app
